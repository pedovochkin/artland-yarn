# ARTLAND — цвет имеет значение

[Открыть сайт](https://pedovochkin.github.io/artland-yarn/)

Витрина бренда пряжи ARTLAND. Крупная типографика, предметный коллаж и интерфейс, вдохновлённый каталогом образцов.

## Что работает

- Подбор пряжи по назначению и переключение образцов с составом и ссылкой на заказ.
- Три цветовых настроения, ручная смена цветов и сохранение своей палитры в SVG.
- Поиск инструкций с переходом к действующим материалам ARTLAND.
- Мобильная навигация и адаптивная вёрстка.

## Запуск

Сборка и установка зависимостей не нужны.

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Структура

- `index.html` — структура и содержимое.
- `style.css` — адаптивная вёрстка.
- `app.js` — каталог, палитра, экспорт SVG, поиск и меню.
- `assets/` — локальные фотографии, логотип и превью для ссылок.

GitHub Pages публикует корень ветки `main`. После изменения файлов достаточно сделать commit и push.

## Версии и материалы

Первая концепция сохранена тегом `v1`, новый вариант — `v2`.

В версии v2 используются реальные фотографии продукции и логотип с предоставленных владельцем сайтов artland-store.ru и пряжа-урал.рф. Права на бренд и фотографии принадлежат их владельцам. Первый постановочный кадр в v1 создан с помощью ImageGen.

Палитра — инструмент вдохновения, а не карта наличия. Актуальные оттенки, цены и заказы открываются в действующем оптовом каталоге «Пряжа-Урал».

Текущие домены, Tilda и адреса опубликованных QR-страниц не менялись.
