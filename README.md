# ARTLAND

Витрина бренда пряжи ARTLAND. Статический сайт без сборки и внешних зависимостей.

## Запуск

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Файлы

- `index.html` — содержимое и структура.
- `style.css` — адаптивная вёрстка.
- `app.js` — фильтры, карточки и поиск инструкций.
- `assets/` — локальные изображения.

Первая версия сохранена тегом `v1`. Публичные адреса существующих сайтов и QR-страниц не менялись. Ссылки на оптовые заказы ведут в действующий каталог «Пряжа-Урал».

Первый постановочный кадр в версии v1 создан с помощью ImageGen. Фотографии товаров и логотип взяты с предоставленных владельцем сайтов ARTLAND и «Пряжа-Урал». Права на бренд и изображения принадлежат их владельцам.
