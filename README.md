# ARTLAND — пряжа, сплетающая мечты

Три визуальные концепции витрины бренда ARTLAND:

- [Вариант 3 — Дом фактур](https://pedovochkin.github.io/artland-yarn/) — текущая главная.
- [Вариант 2 — Цвет имеет значение](https://pedovochkin.github.io/artland-yarn/v2/).
- [Вариант 1 — Всё начинается с нити](https://pedovochkin.github.io/artland-yarn/v1/).

## Третий вариант

24 позиции пряжи и материалов с реальными фотографиями. Фильтры по фактуре, поиск по названию и составу, сортировка по названию и метражу, карточки с характеристиками и избранное, которое сохраняется в браузере.

Раздел мастерской содержит 10 прямых ссылок на оригинальные инструкции с artland-store.ru. Все существующие QR-адреса, Tilda и рабочие домены сохранены.

## Запуск

Сайт статический, без сборки, внешних библиотек и внешних шрифтов.

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. GitHub Pages публикует корень ветки `main`.

## Структура

- `index.html` — витрина и инструкции.
- `style.css` — адаптивная вёрстка.
- `catalogue-data.js` — данные 24 позиций.
- `app.js` — поиск, сортировка, избранное и карточки.
- `assets/` — локальные изображения.
- `v1/`, `v2/` — сохранённые предыдущие варианты.

Теги `v1`, `v2`, `v3` сохраняют версии исходников.

## Данные и изображения

Логотип и сведения о бренде: [ARTLAND](https://artland-store.ru/). Инструкции сверены с публичной картой сайта. Часть фотографий, характеристик и ссылок получены из [оптового каталога «Пряжа-Урал»](https://пряжа-урал.рф/catalogue/artland), часть изображений и характеристик — из [публичной витрины ARTLAND на Terrakot18](https://terrakot18.ru/3811_artland/). Источники каждой позиции сохранены в `catalogue-data.js`.

Права на бренд и изображения принадлежат их владельцам. В варианте 3 используются фотографии реальных товаров. Первый постановочный кадр варианта 1 создан через ImageGen.

Это витрина 24 позиций, а не синхронизированная база складских остатков. Цены и наличие открываются в действующем каталоге «Пряжа-Урал». Для четырёх позиций используется ссылка на общий каталог, когда точный адрес собственной карточки не подтверждён.
